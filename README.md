A simple e-commerce shopping cart application built using **React.js** and **Redux Toolkit**. This project demonstrates state management, routing, and dynamic cart functionality in a modern React application.

---

## 🚀 Features

- 🏠 Home page with category navigation  
- 🛍️ Product listing page  
- ➕ Add to cart / ➖ decrease quantity  
- 🧮 Real-time cart total calculation  
- 🗑️ Remove items / clear cart  
- 🧾 Cart badge with item count  
- 🔁 Redux Toolkit state management  
- 🌐 React Router navigation  

---

## 🧠 Tech Stack

- React.js  
- Redux Toolkit  
- React Redux  
- React Router DOM  
- JavaScript (ES6+)  
- CSS  

---

## 📦 State Management

Redux Toolkit handles global cart state:

### Actions
- addItem  
- decrementItem  
- removeItem  
- clearCart  

### Selectors
- selectCartItems  
- selectCartTotal  
- selectCartCount
